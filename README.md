# Java ATM Management System

##  Project Overview
The **Java ATM Management System** is a console-based application developed using **Core Java**.  
This project simulates the basic working of an ATM machine and helps understand **object-oriented programming (OOP)** concepts and real-world banking operations.

---

##  Features
- User authentication using PIN
- Check account balance
- Cash withdrawal
- Cash deposit
- Mini statement / transaction details
- Secure and user-friendly menu-driven interface

---

##  Technologies Used
- **Programming Language:** Java  
- **Concepts Used:**  
  - OOP (Classes, Objects, Methods)  
  - Conditional Statements  
  - Loops  
  - Exception Handling  
  - Scanner class for user input
